ARCHITECTURE OVERVIEW
================================================================================

Request Flow:
  Client (with JWT) → PublicApi Endpoint → MaxioSubscriptionService
                    → MaxioClient → Maxio API

Layers:
  ApplicationCore  - Configuration and entities (MaxioSettings)
  Infrastructure   - Service implementations (MaxioClient, MaxioSubscriptionService)
  PublicApi        - REST endpoints (Subscription endpoints)

Dependency Injection:
  MaxioSettings       → Singleton
  IMaxioClient        → Transient (via HttpClientFactory)
  IMaxioSubscriptionService → Scoped

Authentication:
  JWT Bearer Token (from /api/authenticate endpoint)
  User claims extracted: NameIdentifier, Email, given_name, family_name
