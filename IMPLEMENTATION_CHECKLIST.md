## Known Limitations

1. **In-Memory Database** — Subscriptions lost on app restart (expected; use SQL Server for persistence)
2. **No Webhook Support** — Subscription state changes are not received from Maxio (add later)
3. **No Payment Methods** — Sandbox plans don't require payment (production plans may differ)
4. **No Subscription Cancellation** — Only create and read operations are exposed (add later if needed)
5. **No Metered Usage Tracking** — Metered component is seeded but not integrated (add later if needed)
