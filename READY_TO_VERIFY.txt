CONFIGURATION PRIORITY
================================================================================

Maxio credentials loaded in this order (first found wins):
  1. User secrets (development)
  2. Environment variables (MAXIO_API_KEY, MAXIO_SITE_SUBDOMAIN, etc.)
  3. appsettings.json configuration section
  4. Default empty values (fails gracefully if endpoints called)

All actual values are NEVER stored in repository files.
