# API Endpoints

This folder demonstrates how to configure API endpoints as individual classes. You can compare it to the traditional controller-based approach found in /Web/Controllers/Api.

## Subscription endpoints

`SubscriptionEndpoints/` adds recurring-subscription billing backed by Maxio Advanced Billing,
alongside - not instead of - the one-time catalog flow. See
[docs/subscriptions.md](../../docs/subscriptions.md) for the routes, the configuration keys and how
repeat subscribe requests are made safe.
