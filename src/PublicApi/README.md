# API Endpoints

This folder demonstrates how to configure API endpoints as individual classes. You can compare it to the traditional controller-based approach found in /Web/Controllers/Api.

## Subscription billing

Recurring-subscription billing (Maxio Advanced Billing) lives in [SubscriptionEndpoints](SubscriptionEndpoints/README.md),
which covers the routes, the idempotency scheme and the `Maxio:` configuration keys.
