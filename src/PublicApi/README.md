# API Endpoints

This folder demonstrates how to configure API endpoints as individual classes. You can compare it to the traditional controller-based approach found in /Web/Controllers/Api.

## PayPal payments & saved cards

The `PaymentEndpoints/` folder adds PayPal-backed payments (authorize → capture → refund/cancel),
saved cards, and a reconciliation report. See [PAYPAL_INTEGRATION.md](PAYPAL_INTEGRATION.md) for the
endpoint list, configuration, and a step-by-step verification guide.
